# 公開ページURLの集計

2026年10月30日時点のチェックアウトを、実際のNuxt/i18nルート生成結果とContentのパス解決に基づいて集計した。**本文・画面を持つ公開ページは1,758 URL。言語選択・自動転送用の233 URLを含めると1,991 URL。** 本番サイトをHTTPクロールして確認した件数ではない。

| 分類 | URL数 | 内訳 |
| --- | ---: | --- |
| ドキュメント | 1,365 | 105 URL × 13言語 |
| ブログ記事 | 106 | 日本語のみ |
| 固定・一覧・ツール等 | 287 | 22 URL × 13言語 ＋ 共通 `/ns/` |
| **公開ページ本体** | **1,758** | 上記の重複を除いた合計 |
| 言語選択・自動転送用 | 233 | 言語プレフィックスなしの105文書＋106記事＋22固定ページ |
| **言語選択・自動転送用を含む合計** | **1,991** | 旧URLリダイレクトは含まない |

1言語あたりのドキュメント105 URLは、Markdown 95件＋YAMLガイド3件＋本文ファイルを持たないディレクトリ一覧7件。後者は `_dir.yml` によりContentの `findOne()` がディレクトリ情報を返し、文書ページのMkIndexが一覧を描画する。実際のContentクエリ処理でも解決できることを確認した。

公開言語は `ja, en, id, ko, it, pl, fr, th, es, de, cn, tw, ja-ks` の13種類。`ja-ks` は日本語原稿を再利用する。原稿のある `ca` は現在の公開言語設定にないため除外した。FAQの91原稿は問い合わせページの一部で、独立したページには数えない。

言語プレフィックスのないURLは、`server/plugins/i18nRedirector.ts` が言語選択・クライアント転送用HTMLへ置き換えるため、ページ本体と分けた。旧Hubリダイレクト・言語名変更のワイルドカード転送・API・アセット・エラーページ・内部 `_dir` URL・クエリ文字列やフラグメントの違いは数えない。末尾スラッシュの違いは同一URLへ正規化した。`noindex` のツールやテストページも公開ルートとして存在するため、固定ページの数には含めている。

集計は381件の実Nuxtルート定義から、旧言語名の転送用ワイルドカード56定義を除き、文書・記事の動的ルートを原稿のパスで展開して行った。静的URL・動的URLの衝突がないことも確認した。
