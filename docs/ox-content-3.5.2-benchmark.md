# Ox Content 3.5.2への更新とFull SSG計測

PR #4のNuxt Content／MDC依存削除構成で、`@ox-content/vite-plugin`と`@ox-content/napi`を **3.4.3 → 3.5.2** へ更新した。3.5.2は更新時にnpmのlatestから確認した版。Vue・Vite・アプリの生成処理・原稿は変更していない。プラグイン内部とアプリ直接利用のN-APIが同じ3.5.2へ解決されることも確認した。

## Full SSG

2026-10-31（JST）、Apple M1 Pro / macOS arm64、Node.js 22.22.2、pnpm 10.27.0、Vue 3.5.25、Vite 8.3.5。Vizeは使用しない。

| Ox Content | 3回の実測 | 中央値 |
| --- | --- | ---: |
| 3.4.3（今回再計測） | 23.18秒 / 21.89秒 / 21.66秒 | **21.89秒** |
| 3.5.2 | 22.28秒 / 22.57秒 / 21.88秒 | **22.28秒** |

中央値の差は **+0.39秒（+1.8%）**。実測範囲は重なっており、各3回の今回の計測では高速化は確認できず、ほぼ同程度だった。小さな差を確定的な速度回帰とは扱わない。前回の3.4.3の22.10秒は歴史的な記録として保持し、今回の比較には今回再測定した21.89秒を使う。

Markdown 1,440件＋YAML 156件、全2,003公開URL＋404、固定Vueページ、クライアントJS/CSS、public資産、旧URL転送を含む。同じ`pnpm benchmark`を使い、PNPM/Node起動から本番ビルド完了までを計測した。3.4.3を3回、依存更新後の3.5.2を3回の順に、すべて新規プロセスで逐次実行。VRTや他のビルドとは同時実行していない。依存インストールと出力検証は時間外。OSキャッシュは保持し、ディスクのcold性能は測っていない。通常のCrowdin準備と既存フォールバックもビルドの一部として実行する。

**全6回でexit 0、全2,003 HTML・404.html・JS/CSS manifestの検証に成功**した。計測前後のソース指紋もそれぞれ不変だった。インストール時間・デプロイ時間・GitHub Actionsの時間は含めていない。

## 更新後の確認

- `pnpm install --frozen-lockfile`成功。
- 回帰テスト25件成功。全1,440 Markdownの構造・属性・メタデータ・コンポーネントpropsと、YAML内201文字列の旧パーサースナップショット比較を含む。
- 実際の生成HTML全2,003 URLを、独立checkoutに残した#3の生成物と照合。表示テキスト（通常の空白を正規化）とコード本文（空白を保持）の差は0件。
- **VRTは今回再実行していない。** 3.4.3時点の画像比較結果を3.5.2の結果へ読み替えない。前回の記録は[依存削除レポート](ox-content-without-mdc.md)に保持する。
